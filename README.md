# Omni Print

Omni Print is a printing solution for Odoo designed to streamline your printing workflow. It allows you to print invoices, reports, and other documents directly from Odoo to any configured printer with a single click—no downloads required.

## How It Works

The solution consists of an Odoo addon and a desktop application. The Odoo addon captures print jobs and sends them to the desktop application, which then directs the jobs to your printer of choice.

## Key Features

*   **One-Click Printing**: Send documents to any configured printer with just a single click.
*   **Cross-Platform Compatibility**: Available for Windows, macOS, and Linux.
*   **Versatile Printer Support**:
    *   Compatible with any wired or network printer recognized by your OS.
    *   Native support for thermal label printers using the ZPL protocol.
    *   Support for ESC/POS receipt printers, working seamlessly with Odoo's PoS module.
    *   Support the preparation printer (for kitchen orders)
*   **Client-Side Rendering**: Render PDFs on the client-side, boosting generation speed by up to 50% and significantly reducing server load compared to server-side rendering.
*   **No Subscription Fees**: A one-time payment model with no recurring fees or print volume limits.
*   **Print History**: Access a complete history of your print jobs at any time.
