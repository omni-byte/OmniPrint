# 🖨️ Omni Print

Omni Print is a printing solution designed for Odoo, enabling one-click direct printing of documents to any configured printer without needing to download files first.

## ✨ Key Features

*   **🖱️ One-Click Printing**: Simplifies your printing workflow.
*   **💻 Cross-Platform**: Supports Windows, macOS, and Linux.
*   **📠 Multi-Printer Compatibility**: Works with regular, thermal label, and receipt printers.
*   **🚀 Client-Side Rendering**: Speeds up PDF generation and reduces server load.
*   **💸 No Subscription Fees**: One-time payment model.

For more information, visit the official website: [https://omni-byte.com](https://omni-byte.com)
